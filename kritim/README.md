# Kritim AI

Frontend entry point for the Kritim AI workspace.

This application is served from:

`https://apps.laxmannepal.com.np/kritim/`

The frontend is intentionally hosted in the Apps repository. The Khoj backend remains separate and can run from Google Colab through Cloudflare Tunnel.

## Architecture

`Apps/kritim` → GitHub Pages / custom domain → Kritim frontend → Khoj backend

Do not place API keys or private credentials in this repository.
